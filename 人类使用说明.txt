Ferret Mail 域名邮箱 - 人类使用说明
文档状态：2026-07-24 已核对

一、这是什么

这是一个把自己的域名变成收件邮箱、临时邮箱或验证码邮箱的程序。

你可以使用：

a@example.com
login@example.com
user001@example.com

系统能接收邮件、识别验证码、显示正文和链接、保存允许大小内的附件。它只负责收件，不能用来发邮件。

二、需要准备什么

1. 一台有固定公网 IPv4 的 Linux 服务器。
2. 一个域名，并把 DNS 托管到 Cloudflare。
3. 云厂商允许入站 TCP 25。
4. 后台全局管理员 Token。

部署人员按“部署教程.md”完成服务器和 systemd 配置。

三、Cloudflare 怎么填

以 example.com 为例，打开 Cloudflare 的 DNS 页面。

第一条：

类型：MX
名称：@
邮件服务器：mail.example.com
优先级：10

第二条：

类型：A
名称：mail
IPv4 地址：服务器公网 IP
代理状态：DNS only / 灰云

mail 这条 A 记录必须是灰云。橙云不能代替 SMTP 邮件转发。

四、怎么打开后台

直接部署时访问：

http://服务器IP:8710/mail

如果部署人员配置了 HTTPS 域名，就使用他提供的 https:// 地址。

输入 PANEL_TOKEN 或当前域名自己的 Token 登录。全局管理员能看到所有主域名；域名 Token 只管理授权范围。

五、第一次怎么验收

1. 打开“运行总览”，确认 HTTP、SMTP、数据库、磁盘和备份没有异常。
2. 执行 DNS 检查。
3. 从其他邮箱发一封邮件到 a@example.com。
4. 确认新邮件出现在列表。
5. 打开详情，确认主题、正文、验证码、链接和附件可用。

只看到后台能打开，不代表 SMTP 收件已经成功；必须实际发信测试。

六、界面怎么用

默认是浅色天蓝白主题。左侧负责域名、别名和管理功能，主区域负责邮件筛选、列表和详情。

折叠区域右侧会显示“展开/收起”。手机上内容会重新排列，主要按钮会保持可触摸大小。若动画让你不舒服，可在系统中开启“减少动态效果”。

七、怎么创建别名

在“新建别名”输入前缀，例如：

login

保存后就是：

login@example.com

别名前缀会转成小写，可使用字母、数字、点、下划线、加号和减号，最长 64 个字符。

没有提前创建也可以收件：只要域名已接入、地址格式合法，收到第一封邮件时系统会自动创建别名。

八、怎么批量生成别名

展开“批量生成”。

可以按序号、日期或随机规则生成预览，确认后再批量创建。批量数量很大时应分批执行，避免浏览器长时间卡顿。

九、怎么查别名和批量操作

展开“搜索与批量操作”：

1. 输入地址或备注搜索。
2. 调整分页。
3. 导出当前域名的别名和接码链接。
4. 进行允许范围内的批量操作。

清空别名不会自动等于清空邮件；执行前看清确认窗口说明的影响范围。

十、怎么筛选邮件

展开邮件区的“筛选与批量操作”，可以按：

- 关键词、发件人、收件人和主题。
- 有验证码、有链接、未读、今天、星标和置顶。
- 日期范围。

选择邮件后可批量已读、未读、星标、取消星标、置顶、取消置顶或删除。遇到 429 提示时先停止连续刷新，稍后再试。

十一、怎么复制验证码

系统识别到验证码后，邮件列表会显示可点击的验证码。点击即可复制，不必先打开详情。

识别结果可能受邮件内容影响。涉及登录、付款或账号恢复时，仍应核对发件人和邮件正文。

十二、怎么看邮件正文

点击邮件进入详情：

- HTML：以隔离的白色阅读画布显示，避免邮件颜色与后台主题混在一起。
- 纯文本：保持换行，适合复制内容。
- 原始内容：用于排查邮件头或解析问题。
- 附件：在权限和大小允许时下载。

读取详情会把这封邮件标为已读。

十三、什么是独立接码链接

每个别名都能生成一个只读接码链接。拿到链接的人只能查看这个别名的邮件，看不到后台其他域名和别名。

在别名卡片中生成并复制链接。可以禁用或重置；重置后旧链接立即失效。

接码链接仍属于敏感访问凭据，不要发给不可信的人。

十四、怎么导出接码链接

打开“邮箱别名”中的“搜索与批量操作”，导出全部别名接码链接 TXT。

没有链接的别名会自动生成并启用。导出文件中的每一行都能访问对应邮箱，应当像密码文件一样保管。

十五、怎么创建子域名

进入“域名管理与接入”，在新增区域输入：

team

系统会生成：

team.example.com

随后严格按面板显示的 Cloudflare 配置添加 DNS，并执行 DNS 检查。不同层级子域名的 MX Name 可能不同，以面板为准。

十六、怎么添加其他主域名

1. 使用全局管理员 Token 登录。
2. 进入“域名管理与接入”。
3. 输入完整域名，例如 example.org。
4. 为 example.org 配置自己的 MX 和 mail A 记录。
5. 需要单独管理时生成主域名 Token。
6. 访问 /mail/example.org。

十七、怎么删除域名

删除子域名：

在目标域名操作区选择“删除子域名”，输入完整域名确认。

删除其他主域名：

使用全局管理员 Token，在“多主域名”中选择“删除主域名”，按界面完成两步确认。

删除前系统会创建保护性备份。删除后，该域名树下的别名、邮件、附件、域名 Token 和接码链接都会失效。默认主域名不能删除。

十八、邮件会保存多久

默认保存 72 小时，域名管理员可以调整保留时间。容量、邮件数和存储配额也可以按域名设置。

临时邮箱不应被当作永久档案。重要邮件和附件请及时保存到其他安全位置。

十九、API 和其他程序接入

后台有“API 文档”和“使用帮助”入口，窄屏时位于“更多”菜单。

动态文档地址：

/api-docs.md
/usage-guide.md

常用自动取件流程是：创建别名、长轮询等待、拉取邮件列表、读取单封详情。管理员 Token 只应放在受控服务端，不要写进公开网页或 App 安装包。

二十、Webhook

域名设置可以填写 Webhook URL。每次收信成功后，系统会异步 POST 邮件摘要。

当前 Webhook 没有签名、自动重试或重定向跟随。接收地址应使用 HTTPS 和随机不可猜路径，并按邮件 ID 做幂等处理。

二十一、删除、清空和恢复提示

删除单封邮件会简短确认；清空、删除域名和恢复备份会要求输入目标名称或确认词。

恢复备份会覆盖当前数据库。不要在没有新备份、没有核对文件名时操作。

二十二、收不到邮件怎么办

按顺序检查：

1. 云厂商是否允许入站 25。
2. 安全组和服务器防火墙是否放行 25。
3. 服务是否正在运行，SMTP 是否监听。
4. MX 是否指向 mail.example.com。
5. mail A 记录是否指向正确公网 IP 且为灰云。
6. PUBLIC_IP 是否正确。
7. 域名是否启用，是否超出邮件数或存储配额。
8. 查看后台失败邮件和服务器日志。

二十三、后台打不开或登录失败

- 检查地址、端口、HTTPS 反向代理和服务状态。
- 检查请求使用的域名是否已加入 TRUSTED_HOSTS。
- 确认 Token 没有多余空格，且属于当前域名。
- 域名 Token 可能已被禁用或重置。
- 如果连续输错触发限流，停止尝试后稍等。

二十四、开源版说明

这个目录不包含真实域名、生产 IP、Token、SSH 密码、数据库、附件、日志或备份。部署时必须填写自己的环境变量。
